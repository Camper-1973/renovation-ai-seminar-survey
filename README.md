# renovation-ai-seminar-survey

30秒で回答できるリノベーション業界向けAI課題アンケート。Google Apps Scriptで回答保存・集計表示を行うセミナー実演用ツール。

## v0.1 の構成

- `Code.gs` — 回答保存、スプレッドシート自動作成、集計処理
- `Index.html` — 参加者向けスマホフォーム
- `Dashboard.html` — 講演者向け集計画面
- `appsscript.json` — Apps Script設定

## 回答データ

初回に `setup()` を1回実行すると、Google Driveに次のスプレッドシートを自動作成します。

`リノベ業界AI課題アンケート_回答データ`

以後の回答は、そのスプレッドシートの `回答データ` シートへ1回答1行で保存されます。

保存項目：

- 回答日時
- 会社名
- 名前
- 立場
- 属人化している仕事
- 繰り返している仕事
- AIで楽にしたい仕事
- アプリバージョン

会社名・名前は回答データには保存しますが、集計画面には表示しません。

## 初期設定

1. Google Apps Scriptで新しいプロジェクトを作る
2. このリポジトリの `Code.gs`、`Index.html`、`Dashboard.html`、`appsscript.json` を配置する
3. Apps Scriptエディタから `setup()` を1回実行する
4. 権限を許可する
5. 実行結果または `getSpreadsheetInfo()` で保存先スプレッドシートを確認する

## Webアプリ公開

Apps Scriptの「デプロイ」→「新しいデプロイ」→「ウェブアプリ」。

推奨設定：

- 実行するユーザー：自分
- アクセスできるユーザー：全員

参加者用URL：

`https://script.google.com/macros/s/XXXXX/exec`

集計画面：

`https://script.google.com/macros/s/XXXXX/exec?mode=dashboard`

## 集計方法

v0.1では常時ポーリングしません。

集計画面を開いた時に最新データを読み込み、その後は「最新の集計を読む」ボタンを押した時だけ再集計します。セミナー中に不要なアクセスを増やさず、安定性を優先しています。

表示内容：

- 総回答数
- 「人に依存している仕事」上位3件
- 「何度も繰り返している仕事」上位3件
- 「AIで楽にしたい仕事」上位3件
- `属人化 × 繰り返し × AIへの期待` の一覧

## 想定利用

1. スライドに参加者用URLのQRコードを表示
2. 会場参加者が30秒程度で回答
3. 回答はGoogleスプレッドシートへ蓄積
4. 講演者が集計画面を開く、または更新ボタンを押す
5. その場で会場全体の傾向を見る
