# renovation-ai-seminar-survey

リノベーション協議会などのセミナーで使う、1分の「リノベ業界タイプ診断」ツールです。

参加者はスマホで5問に回答し、その場で自分の診断タイプを確認します。回答はGoogleスプレッドシートに保存され、講演者側の集計画面で会場全体のタイプ分布や立場別の傾向を表示できます。

## 構成

- `Code.gs` — 回答保存、診断判定、スプレッドシート自動作成、イベント別集計処理
- `Index.html` — 参加者向けスマホ診断フォーム
- `Dashboard.html` — 講演者向け集計画面
- `appsscript.json` — Apps Script設定
- `docs/` — GitHub Pages用デモ。Googleスプレッドシートには保存しません。

## 本番GAS版の流れ

1. 参加者がイベントID付きQRコードからフォームを開く
2. 会社名・名前・5問に回答
3. GASが診断タイプを判定
4. 回答とイベントIDをGoogleスプレッドシートへ1行保存
5. 参加者のスマホに診断結果を表示
6. 講演者がイベントID付きの集計画面を開く
7. 指定イベントの回答だけを読み込み、会場全体の結果を表示

## イベントID

同じWebアプリを複数のセミナーで流用するため、URLの `event` パラメータで開催回を識別します。

推奨形式：

`場所-YYYY-MM-DD-時間帯`

例：

- `sendai-2026-10-08-pm`
- `sapporo-2026-10-22-pm`

2026年10月8日午後の仙台開催では次の形式を使用します。

参加者用：

`https://script.google.com/macros/s/XXXXX/exec?event=sendai-2026-10-08-pm`

集計画面：

`https://script.google.com/macros/s/XXXXX/exec?mode=dashboard&event=sendai-2026-10-08-pm`

URLを後日別の人が開いて回答した場合も、そのQRコードに付いているイベントIDで記録されます。回答日時は別途保存されるため、会場当日と持ち帰り後の回答は日時で判別できます。

集計画面で `event` を省略すると全イベントを合算表示します。

## 回答データ

初回に `setup()` を1回実行すると、Google Driveに次のスプレッドシートを自動作成します。

`リノベ業界タイプ診断_回答データ`

保存項目：

- 回答日時
- 会社名
- 名前
- 立場
- 参加理由
- テンションが上がる瞬間
- 会社として伸ばしたいこと
- 提供できること
- 診断タイプ
- アプリバージョン
- イベントID
- 開催地
- 開催日
- セッション

既存の16列版シートは、更新後のコードがイベント列を右側に追加して自動移行します。

会社名・名前は回答データには保存しますが、集計画面には表示しません。

## 初期設定

1. Google Apps Scriptで新しいプロジェクトを作る
2. このリポジトリの `Code.gs`、`Index.html`、`Dashboard.html`、`appsscript.json` を配置する
3. Apps Scriptエディタから `setup()` を1回実行する
4. 権限を許可する
5. 実行結果または `getSpreadsheetInfo()` で保存先スプレッドシートを確認する

`.clasp.json` はPC固有のGAS接続設定なのでGitHubには登録せず、`.gitignore` で除外します。

## Webアプリ公開

Apps Scriptの「デプロイ」→「新しいデプロイ」→「ウェブアプリ」。

推奨設定：

- 実行するユーザー：自分
- アクセスできるユーザー：全員

初回デプロイ後、発行された `/exec` URLにイベントIDを付けてQRコードを作成します。

## 集計方法

常時ポーリングはしません。

集計画面を開いた時に最新データを読み込みます。回答が増えた後は「最新表示」ボタンを押すと、その時点のスプレッドシート内容で再集計します。

## スライドでの使い方

1. イベントID付き参加者URLのQRコードを表示する
2. 参加者に1分で診断してもらう
3. 入力中に「これはAI活用の縮小版です」と説明する
4. 同じイベントID付き集計画面を別タブで全画面表示する
5. 会場全体のタイプ分布と立場別傾向を見せる
6. 交流会で話しかけるきっかけにする
