# renovation-ai-seminar-survey

セミナー参加者向けの v0.6.1「リノベ業界 生態系診断」です。

参加者はスマホで10問に回答し、仕事上の選択傾向を動物タイプとして確認できます。回答はGoogleスプレッドシートへ保存され、講演者向けダッシュボードではイベント別・立場別の生態系を表示します。

## v0.6 系の診断

回答を「行動力、主導力、対人力、分析力、感性、適応力」の6軸へ加点し、0〜100に正規化します。10動物それぞれの理想プロファイルとの距離にタイプ別補正を加え、最も近い動物を本タイプ、次に近い動物を隠れタイプとして返します。

対象動物：🦁ライオン、🐺オオカミ、🦍ゴリラ、🐗イノシシ、🐋クジラ、🦉フクロウ、🦊キツネ、🦝タヌキ、🐈ネコ、🐇ウサギ

すべてのタイプを仕事上の強みとして表現し、性格検査や科学的診断を装わない設計です。

## v0.6.1 同時アクセス対策

セミナー会場で複数人が同時に「生態系を診断する」を押す状況を想定し、回答送信処理を軽量化しています。

- 回答送信のたびにシート初期化・見出し確認・書式設定を行わない
- Spreadsheetを開く処理はロック取得前に行い、ScriptLockは回答1行の追記部分だけに限定
- 10秒待機の `waitLock` をやめ、5秒の `tryLock` で混雑時は明示的に再試行を案内
- 回答保存直後のイベント全件走査 `countEventResponses_()` を送信処理から外し、結果表示までの待ち時間を短縮
- イベント別集計は従来どおりダッシュボード側で取得する

既存の診断ロジック、イベントID、回答列、ダッシュボード集計は変更していません。

## 画面とファイル

- Code.gs — 採点、距離判定、保存、イベント別集計、シート移行
- Index.html — 参加者向け10問フォームとスクショ用結果カード
- Dashboard.html — 講演者向けの会場・立場別動物分布
- appsscript.json — Apps Script設定
- docs/ — GitHub Pages用デモ

結果カードには、動物・キャッチコピー・入力内容からの分析・6軸スコア・隠れタイプ・交流会での具体的アプローチ・相性のいい動物2種・北海道企業とのコラボ案・スクショ案内を表示します。参加者画面からダッシュボードへのリンクは出しません。

## イベント別URL

イベントIDの推奨形式は 場所-YYYY-MM-DD-時間帯 です。

参加者用：

    https://script.google.com/macros/s/XXXXX/exec?event=sendai-2026-10-08-pm

ダッシュボード：

    https://script.google.com/macros/s/XXXXX/exec?mode=dashboard&event=sendai-2026-10-08-pm

イベントID、開催地、開催日、セッションによる既存のイベント別保存・集計は維持しています。ダッシュボードで event を省略すると全イベントを合算します。

## 既存回答データとの互換性

従来の先頭20列は列位置・見出し・保存済みデータを変更しません。v0.5.0で右側に次の18列を追加しています。

- 診断Q1〜診断Q10
- 行動力、主導力、対人力、分析力、感性、適応力
- 隠れタイプキー、隠れタイプ

旧バージョン回答は削除せず、ダッシュボードの回答総数には含めますが、10動物の分布からは除外して件数を注記します。

## GAS側の更新手順

1. リポジトリ付属の更新BATで最新の main を取得し、GASへ反映する
2. 初回導入時、または回答シートが存在しない場合はApps Scriptエディタで `setup()` を1回実行する
3. Apps Scriptの「デプロイ」→「デプロイを管理」→既存デプロイの編集を開く
4. バージョンを「新バージョン」にして更新する

既存デプロイを更新すれば /exec URLとイベント別QRコードは変わりません。新しいデプロイを作る必要はありません。初回導入時のみ `setup()` を実行して権限を許可し、回答先スプレッドシートを作成してください。

## 秘密情報

.clasp.json、.env、APIキー、token、credentials、秘密鍵などはコミットしません。GASのスプレッドシートIDはScript Propertiesの SURVEY_SPREADSHEET_ID に保存します。会社名・氏名は回答シートだけに保存し、ダッシュボードには返しません。
