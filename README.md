# renovation-ai-seminar-survey

リノベーション協議会などのセミナーで使う、1分の「リノベ業界タイプ診断」ツールです。

参加者はスマホで5問に回答し、その場で自分の診断タイプを確認します。回答はGoogleスプレッドシートに保存され、講演者側の集計画面で会場全体のタイプ分布や立場別の傾向を表示できます。

## 構成

- `Code.gs` — 回答保存、診断判定、スプレッドシート自動作成、集計処理
- `Index.html` — 参加者向けスマホ診断フォーム
- `Dashboard.html` — 講演者向け集計画面
- `appsscript.json` — Apps Script設定
- `docs/` — GitHub Pages用デモ。Googleスプレッドシートには保存しません。

## 本番GAS版の流れ

1. 参加者がQRコードからフォームを開く
2. 会社名・名前・5問に回答
3. GASが診断タイプを判定
4. 回答をGoogleスプレッドシートへ1行保存
5. 参加者のスマホに診断結果を表示
6. 講演者が `?mode=dashboard` の集計画面を開く
7. スプレッドシートの回答を読み込み、会場全体の結果を表示

## 診断タイプ

- 🔥 ゴリゴリ開拓タイプ
- 🔍 新商品ハンタータイプ
- 🤝 つなぐ人タイプ
- 🧠 現場の軍師タイプ
- 🛠️ 解決屋タイプ
- 👀 様子見スカウトタイプ

## 回答データ

初回に `setup()` を1回実行すると、Google Driveに次のスプレッドシートを自動作成します。

`リノベ業界タイプ診断_回答データ`

保存項目：

- 回答日時
- 会社名
- 名前
- 立場
- 参加理由
- テンションが上がる瞬間
- 会社として伸ばしたいこと
- 提供できること
- 診断タイプ
- アプリバージョン

会社名・名前は回答データには保存しますが、集計画面には表示しません。

## 初期設定

1. Google Apps Scriptで新しいプロジェクトを作る
2. このリポジトリの `Code.gs`、`Index.html`、`Dashboard.html`、`appsscript.json` を配置する
3. Apps Scriptエディタから `setup()` を1回実行する
4. 権限を許可する
5. 実行結果または `getSpreadsheetInfo()` で保存先スプレッドシートを確認する

## Webアプリ公開

Apps Scriptの「デプロイ」→「新しいデプロイ」→「ウェブアプリ」。

推奨設定：

- 実行するユーザー：自分
- アクセスできるユーザー：全員

参加者用URL：

`https://script.google.com/macros/s/XXXXX/exec`

集計画面：

`https://script.google.com/macros/s/XXXXX/exec?mode=dashboard`

## 集計方法

常時ポーリングはしません。

集計画面を開いた時に最新データを読み込みます。回答が増えた後は「最新表示」ボタンを押すと、その時点のスプレッドシート内容で再集計します。

## スライドでの使い方

1. QRコードを表示する
2. 参加者に1分で診断してもらう
3. 入力中に「これはAI活用の縮小版です」と説明する
4. 集計画面を別タブで全画面表示する
5. 会場全体のタイプ分布と立場別傾向を見せる
6. 交流会で話しかけるきっかけにする
